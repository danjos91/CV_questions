When did the fastest kilometer start?

Each number is meters run in that minute. Find a contiguous stretch whose sum is at least 1000 m, then report its 1-based starting minute. If several stretches qualify, the tie-breakers on the right decide.

Sliding window Sum ≥ 1000 m Output = start minute Time O(n)

Pick the winning interval

  1. 1Shortest length (fewest minutes).
  2. 2If tied, largest total meters.
  3. 3If still tied, the one that started earlier.

The two-pointer scan expands right, then shrinks left while the window still covers a kilometer.

Why this works

  1. Add minute right to the sum.
  2. While dropping a[left] still leaves ≥ 1000, move left forward. The window is then the shortest suffix of [0..right] that still covers a kilometer.
  3. If the window is valid, keep it when it is shorter, or equally short with more meters (or the same meters but an earlier start).
  4. Print bestStart + 1. Left only moves forward, so the whole scan is O(n).

How to read it

  1. Minute 1 is the first number. Output is that 1-based index, not the length.
  2. A valid window can be longer than 1000 m — you may not drop a minute if that would fall below the goal.
  3. Hover a candidate chip under the chart to preview that window.
  4. Keys: Space / → step, P play, R reset, A answer.
